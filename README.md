Power BI Data Cleaning & Quality Checks
Overview
This project demonstrates a structured data-cleaning and quality-control workflow using Power BI and Power Query.
The raw dataset contains product and mould information with duplicate records, inconsistent text formats, missing values, invalid dates, and unusual numerical values. The objective was to identify these issues, standardize the data, and document records requiring further verification.
Tools Used
• Power BI Desktop
• Power Query
• Microsoft Excel
• Data profiling and validation rules
Data Quality Checks
The project includes:
• Identification of duplicate records
• Standardization of names and text formats
• Removal of unnecessary spaces
• Detection of missing values
• Validation of inspection dates
• Validation of mould cavities and weight values
• Standardization of ERP statuses
• Creation of individual quality-check columns
• Creation of a consolidated Data_Quality_Note column
• Identification of records requiring verification before ERP upload
